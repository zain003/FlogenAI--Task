# Rule: Progress Tracking Protocol

Every prompt execution and implementation task must maintain the project progress record:

- Check `context/progress-tracker.md` to identify the current goal and active feature.
- Never skip ahead in the feature pipeline without completing the active feature's verification.
- Update `context/progress-tracker.md` upon every successful feature verification and link the corresponding test report from `feature-test-reports/`.
- Log any unresolved questions or architectural decisions with clear rationale.
- Source of truth: `context/progress-tracker.md`.
